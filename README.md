# CS386Bot Question Assets

Public, student-facing images used by CS386Bot assignment questions.

## Rules

- Store only material that students are allowed to see.
- Do not store answer keys, rubrics, grading rules, credentials, or student data.
- Organize assets under `assignments/<assignment-key>/<question-id>/`.
- Reference images with commit-pinned raw GitHub URLs so published questions remain reproducible.

## Recovered teaching figures

`asset-manifest.json` records the original attachment URL, file path, SHA-256,
media type, dimensions, and byte size for 40 recovered course reference images.
The files preserve the original bytes. Only teaching figures already present in
student-facing prompts are included; private grading material stays separate.

Use the complete 40-character commit SHA in `raw.githubusercontent.com` links.
Keep existing files and commits available for released assignments. Add a new
version and update the question's pinned URL when a figure changes. Never point
released questions at `main`, temporary signed URLs, or private attachments.

Before publishing a question, fetch its exact pinned image URL without staff
credentials, check its media type and decoded dimensions, and visually review
it. The private content repository's image checker rejects private attachments
and moving image URLs and offers an unauthenticated network check.
