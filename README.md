# CS386Bot Question Assets

Public, student-facing images used by CS386Bot assignment questions.

## Rules

- Store only material that students are allowed to see.
- Do not store answer keys, rubrics, grading rules, credentials, or student data.
- Organize assets under `assignments/<assignment-key>/<question-id>/`.
- Reference images with commit-pinned raw GitHub URLs so published questions remain reproducible.
